# Security Policy

This is a local desktop application: it makes one optional IP-geolocation
request on first run (see Privacy in README) and otherwise works offline.

If you find a security issue (e.g. command injection via file paths,
unsafe deserialization, privilege problems in packaging scripts), please
report it via a **private** channel:

- Email: H.Z.Tun <htoz27@users.noreply.github.com>, or
- GitHub private vulnerability reporting on this repository.

Please do not open public issues for security-sensitive reports.
